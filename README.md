This repository contains the materials needed to construct the KF 40 Wisconsin Oscillator circuit as described in this JASMS publication.
We intend this information to be freely available for academic researchers and students, but any entity intending to use these materials in a for-profit manner must contact the authors and receive permission for their use.

If you are interested in the original implementation of the Wisconsin Oscillator, please see follow this link for fabrication files and instructions: https://github.com/uw-madison-chem-shops/wisconsin-oscillator 

For questions, please contact us at sjkregel@fsmail.bradley.edu
